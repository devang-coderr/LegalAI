How to Run Frontend-1
1. Open Command Prompt / PowerShell

Navigate to the LegalAI repository:

cd "PATH_TO_YOUR_LEGALAI_FOLDER"

Example:

cd "C:\Users\devan\Downloads\LegalAI"
2. Open Frontend-1
cd frontend-1
3. Install dependencies
npm install
4. Start the development server
npm run dev

You should see something similar to:

Local: http://localhost:3000

Open the displayed address in your browser.

▶️ How to Run Frontend B

Open a new Command Prompt / PowerShell or return to the LegalAI folder:

cd "PATH_TO_YOUR_LEGALAI_FOLDER"

Then:

cd legalai-frontend(2)

Install dependencies:

npm install

Start the development server:

npm run dev

Then open the local address shown in the terminal, usually:

http://localhost:3000
⚠️ Important

Do not upload or commit these folders/files:

node_modules/
.next/
.env
.env.local

These are either generated automatically or may contain sensitive information.

The following files should remain in the repository:

package.json
package-lock.json
.env.example
src/
public/

If you need the dependencies again, simply run:

npm install
